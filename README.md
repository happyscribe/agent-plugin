# HappyScribe Agent Plugin

Portable [Agent Plugin](https://agent-plugins.org) for HappyScribe: connects your AI agent to the official HappyScribe MCP server and adds three ready-made skills.

- **MCP server:** `https://www.happyscribe.com/mcp` (Streamable HTTP). Sign in with your HappyScribe account (OAuth) the first time a tool runs.
- **Skills:** `meeting-notes`, `transcribe-media`, `verify-quotes`.

Docs: https://help.happyscribe.com/en/articles/13927840-what-is-happyscribe-mcp
